# MacroManager 💪

Contador de macros personal. Simple, gratuito y offline.


## Info
La aplicación solamente guarda datos en local con una base de datos SQLite.
Las búsquedas de alimentos en internet solamente busca la información y la guarda en local en caso de que el usuario le de a guardar.
La aplicación es de libre y gratuito uso.
Para búsquedas de información nutricional usa [Open Food Facts](https://world.openfoodfacts.org/)

## Descarga y/o uso de la aplicación:
Entrar a la web por el enlace [Visitar Web](https://rafamolportillo03.github.io/macromanager/).
Dentro de la web podemos usarla con normalidad.
En caso de querer descargarla:
- Le damos a los 3 puntos del navegador.
- Vamos a donde dice añadir a la pantalla de inicio.
- Nos saldrán dos opciones, instalar y crear acceso directo;
  - Si le damos a instalar podremos usar la web como una aplicación común dentro del dispositivo, incluso si no tiene internet "(sin internet no podremos buscar la información nutricional de los alimentos, pero si añadir los nuestros o los que hayamos añadido anteriormente)".
  - La otra opción es crear acceso directo, la cual sirve para conectarse a la web fuera del navegador, pero no podremos usarla sin internet.
